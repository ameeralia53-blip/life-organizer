# يومك بيدك - Life Organizer

A modern, Arabic RTL Single Page Application (SPA) built with React and Vite for organizing your daily life.

## 🚀 Features

1. **Weekly Tasks (مهام أيام الأسبوع)** - Plan your tasks for each day of the week
2. **Mind Map (الخطة الذهنية)** - Write comprehensive plans and strategies
3. **Free Notes (تدوين حر وتذكير)** - Daily journaling and reminders
4. **Study Plan (المخطط الدراسي)** - Organize your subjects and study hours
5. **Alarm/Timer (المنبه)** - Set timers with visual and audio alerts
6. **Archive (المحفوظات الشاملة)** - View and manage all saved data

## 🛠️ Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling
- **React Router** - Navigation
- **Lucide React** - Icons
- **LocalStorage** - Data persistence

## 📦 Installation

```bash
npm install
```

## 🏃 Running the Application

### Development

```bash
npm run dev
```

The app will open at `http://localhost:5173`

### Production Build

```bash
npm run build
npm run preview
```

## 📱 Features Details

### Weekly Tasks
- Create tasks for each day of the week
- Save up to 10,000 characters per day
- Mock file attachment button
- Delete tasks functionality

### Mind Map
- Write comprehensive plans
- Unlimited text storage
- Mock PDF attachment
- Auto-save capability

### Free Notes
- Infinite journaling and note-taking
- Persistent storage
- Clear all functionality

### Study Plan
- Add up to 15 subjects
- Track study hours
- Automatic total hours calculation
- Delete subjects

### Alarm/Timer
- Input minutes for timer
- Visual countdown display
- Audio alert when time expires
- Modal alert notification

### Archive
- View all saved data
- Expandable sections
- Data download as JSON
- Clear all data with confirmation

## 💾 Data Persistence

All data is stored in browser's `localStorage`. It persists even after closing the browser.
